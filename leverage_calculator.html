计算公式说明

自有资金

自有资金 = 资产总价值 - 负债总额

= {{ fmtMoney(assetValue) }} - {{ fmtMoney(loanAmount) }} = {{ fmtMoney(equity) }}

资产负债率

资产负债率 = 总负债 / 总资产

= {{ fmtMoney(loanAmount) }} / {{ fmtMoney(assetValue) }} = {{ (debtToAssetRatio * 100).toFixed(2) }}%

负债权益比

负债权益比 = 总负债 / 股东权益

= {{ fmtMoney(loanAmount) }} / {{ fmtMoney(equity) }} = {{ debtToEquityRatio.toFixed(4) }}

权益乘数

权益乘数 = 总资产 / 股东权益 = 1 + 负债权益比

= {{ fmtMoney(assetValue) }} / {{ fmtMoney(equity) }} = {{ equityMultiplier.toFixed(4) }}
