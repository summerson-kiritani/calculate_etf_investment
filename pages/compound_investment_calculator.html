计算模型、质押借贷（买借死）策略与蒙特卡洛原理说明

1. 股票质押借贷（Buy, Borrow, Die / 买借死）策略模型

股票资产递推：A_t = A_{t-1} × (1 + R_q) + 定投额（股票全额保留在场内享受市场收益，不做任何卖出割肉）

负债滚雪球：D_t = D_{t-1} × (1 + r_{loan_q}) + 当期借款额 W_t（负债按质押年利率以季度复利累加）

净资产 NW_t = A_t - D_t | 质押率 LTV_t = D_t / A_t

爆仓清算条件：当 NW_t ≤ 0 (即 LTV_t ≥ 100%) 时，触发强平抵扣负债，净资产归零并标记模拟终止/失败路径。

2. 提领算法与抗通胀调整

百分比模式：当期提领/借款额 = 当前股票总资产 × 提领比例 (%)

固定抗通胀模式：当期提领/借款额 = 基准首年额度 × (1 + 年通胀率)^(经过年数)

3. 蒙特卡洛随机模拟与序列收益爆仓风险

每季度随机收益率 R_q ~ Normal(μ_q, σ_q)（使用 Box-Muller 正态随机采样）

在质押借贷模式下，若退休初期遭遇暴跌熊市，股票资产缩水而负债仍按利滚利增长，极易导致 LTV 飙升而爆仓破产。蒙特卡洛模拟能精确评估这一风险概率。

4. 内部收益率 (IRR) 计算原理

使净现值 NPV = ∑ [ CF_t / (1 + IRR_q)^t ] = 0

在质押模式中，现金流序列为：前期的追加定投本金（-），退休后质押借出的到手现金（+），以及最后一期清偿负债后的剩余净资产（+$NW_T$）。该 IRR 能精准测量整套质押提领策略的真实资金年化化利用率。
