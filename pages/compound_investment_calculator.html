计算公式与多条件规则说明

1. FIRE 退休与停止定投条件触发逻辑

停止定投触发：满足 [年龄 >= 设定期限] 或 [总资产 >= 设定门槛] 或 [投入本金 >= 设定门槛] 时终止后续投入

FIRE 目标资产总额 = 预计年开销 × 目标倍数（传统 FIRE 为 25 倍，推荐设为 33 倍）

退休阶段触发：满足 [年龄 >= 退休年龄] 或 [总资产 >= FIRE目标资产] 或 [当年可提领额 >= 提领门槛] 时开启每年Q4提领

2. 季度复利与提领计算

FV_raw = 上期末账户余额 × (1 + 季度修正收益率) + 当季定投投入

提领金额 = FV_raw × 提领率（仅退休后每年 Q4 执行）

期末账户余额（名义数字） = FV_raw - 提领金额

3. 通货膨胀与实际购买力折算

折算因素 (Discount Factor) = (1 + 年通胀率)^(经过年数)

期末余额 (今日购买力) = 期末账户余额 ÷ 折算因素
