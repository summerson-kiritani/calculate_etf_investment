金融与投资评估指标说明

1. 首付现金回报率 (Cash-on-Cash Return)

衡量投资者初始自备资金的现金收益能力，对按揭贷款投资至关重要。

CoC = (首年租金收入 - 首年持有成本 - 首年还贷总额) ÷ 初始总投入 × 100%

2. 内部收益率 (IRR)

考虑了整个持有期间各年现金流及期末卖房（扣除交易中介税费与未清贷款）后的综合年化投资回报率（使 NPV = 0 的折现率）。

- InitialOutflow + Σ [ CashFlow_t / (1+IRR)^t ] + NetEquity_N / (1+IRR)^N = 0

3. 净现值 (NPV)

按预设基准折现率将未来所有现金流折算至今天的价值。NPV > 0 表示该投资收益跑赢了预设基准收益率（如国债或无风险理财）。

4. 等额本息月供公式

月供 = [贷款本金 × 月利率 × (1+月利率)^月数] ÷ [(1+月利率)^月数 - 1]
