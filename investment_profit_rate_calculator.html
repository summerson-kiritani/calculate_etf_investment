计算公式说明

总收益率

总收益率 = (卖出价 - 买入价) × 份额 / (买入价 × 份额)

= ({{ sellPrice.toFixed(2) }} - {{ buyPrice.toFixed(2) }}) × {{ shares.toFixed(2) }} / ({{ buyPrice.toFixed(2) }} × {{ shares.toFixed(2) }}) = {{ (profitRate * 100).toFixed(2) }}%

月化收益率

月化收益率 = (1 + 总收益率)^(1/持有月数) - 1

= (1 + {{ (profitRate * 100).toFixed(2) }}%)^(1/{{ holdMonths }}) - 1 = {{ (monthlyReturn * 100).toFixed(3) }}%

日化收益率

日化收益率 = (1 + 月化收益率)^(1/30) - 1

= (1 + {{ (monthlyReturn * 100).toFixed(3) }}%)^(1/30) - 1 = {{ (dailyReturn * 100).toFixed(4) }}%

年化收益率

年化收益率 = (1 + 月化收益率)^12 - 1

= (1 + {{ (monthlyReturn * 100).toFixed(3) }}%)^12 - 1 = {{ (annualReturn * 100).toFixed(2) }}%
