贷款方案：一次性投入基金

FV = P × beta × (1 + 基金年化收益率)^年数

= {{ fmtMoney(loanPrincipalInput) }} × {{ lumpSumBeta }} × (1 + {{ fundRate }}%)^{{ loanTerm.toFixed(2) }} = {{ fmtMoney(fundValueLumpSum) }} 元

闲置资金 = P × (1 - beta) = {{ fmtMoney(idleCapital) }} 元

定投方案：每月定投基金

FV = PMT × [ (1+r)^n - 1 ] / r × (1 + r)

月基金收益率 = {{ monthlyFundRate.toFixed(6) }}

FV = {{ fmtMoney(fundValueMonthly) }} 元

累计本金 = {{ fmtMoney(monthlyCashFlow) }} × {{ totalMonths }} = {{ fmtMoney(totalMonthlyInvestment) }} 元
